## 🎨 Especificaciones técnicas comunes (todos los reels)

**Setup:**
- Cámara: Osmo Pocket 3
- Audio: micrófono DJI cerca al pecho (15-25cm)
- Fondo: gris oscuro (#1a1a1a)
- Vestuario: camisa oscura sólida (negro/gris carbón/azul marino)
- Iluminación: 45° lateral cálida (3200K-3500K)

**Estética:**
- Estilo: Dan Koe + Naval Ravikant (autoridad tranquila)
- Tipografía superpuesta: blanco puro o cyan suave (#a4d8d8)
- Cortes: hard cuts cada 5-7s (no transiciones decorativas)
- Cierre: logo CreaTuActivo + queswa.app en últimos 2s

**Tono:**
- Lujo Clínico — frío matemático
- "Usted" universal (cero tuteo)
- Cero exclamaciones, cero hype
- Reel Servidor Público: variante reflexiva (más pausada)

## 🚀 Flujo de producción

```
1. Seleccionar reel/servilleta según avatar destino
2. Auditar el guión contra Glosario v1.4
3. Memorizar teleprompter (script estructura second-by-second incluida en cada reel)
4. Setup técnico (camera/audio/luces)
5. Grabar con cortes secos cada 5-7s
6. Editar (B-roll codificado descrito en cada reel)
7. Distribuir vía plantillas de saludo 1-a-1 (incluidas en cada reel)
8. Medir 7 días → decidir validación o pivote
```

## 📊 Validación de hooks (testing 7 días)

Cada reel incluye su plan de testing y métricas. Métricas comunes:

| Métrica | Fracaso | Esperado | Éxito |
|---|---|---|---|
| Thumb-stop rate (3s) | <20% | 35-45% | >55% |
| Retención completa | <10% | 18-25% | >35% |
| CTR a Queswa | <5% | 10-15% | >20% |
| Auditorías iniciadas | 0-2 | 6-10 | >12 |
