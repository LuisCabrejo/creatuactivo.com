# Guiones aprobados

**Un archivo por guion.** Aquí entra solo lo que el Director aprobó, y se marca si ya se
emitió o si está aprobado y pendiente de grabar.

**Qué NO es esto.** [REELS_DIARIOS_DOCUMENTACION.md](../REELS_DIARIOS_DOCUMENTACION.md)
sigue siendo la **bitácora cronológica** —el hilo de la serie, con sus notas de producción y
sus semillas sin producir—. Este directorio es el **texto limpio y citable**: lo que se dijo,
tal como se dijo, sin el aparato alrededor. Cuando alguien pregunte *«¿cómo quedó el del día
uno?»*, la respuesta está acá en un archivo, no enterrada en un documento de mil líneas.

**Nombre del archivo:** `AAAA-MM-DD-serie-dia-NN-titulo-corto.md`.

**Cada archivo lleva, en este orden:**

1. Cabecera con fecha, serie y día, estado (`emitido` · `aprobado, sin grabar`), formato,
   dónde se publicó y duración de cada versión.
2. **El guion verbatim**, sin anotaciones intercaladas — para poder copiarlo tal cual.
3. Las frases que se suprimen en la versión corta, si hay dos versiones de un mismo rodaje.
4. **Por qué quedó así:** las decisiones de guion que costaron discusión. Es lo que evita que
   el próximo lo «mejore» de vuelta hacia donde ya estuvo.

⚠️ **Un guion emitido no se edita.** Si el copy cambia, se escribe un archivo nuevo. Lo que
ya salió al aire es registro, y el registro no se corrige — se sucede.
